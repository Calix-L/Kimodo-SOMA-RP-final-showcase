三、Phase 2 数据转换与失败实验

数据管线

21,529 原始动作 → 约 9,000 单人动作 → 7,951 keep_human → 骨架重定向与中性手腕修复 → 30 fps → 90×369 特征 → 6,532 / 1,419 划分。

三条失败路线

  1. batch=8、3,000 steps：loss 下降、推理正常，强动态动作没有稳定增强。
  2. 加噪 + MSE：数值收敛但可视化仍不理想。
  3. 不做 normalized：位置、朝向、骨架尺度和特征范围不统一，Structured Loss 各项失衡。

一致现象是脚像钉在地板上，模型保留站立与足底接触先验。结论是 loss 下降不等于学会离地、浮空和落地，不能继续只调 batch、学习率或优化器。

四、Structured Motion Loss 与两阶段训练

总损失由 Root Position、Root Heading、Joint Position、Joint Velocity、Joint Rotation、Foot Contact 与 FK Position 七项 masked Smooth L1 组成，论文权重为 10 / 2 / 10 / 3 / 10 / 4 / 5。

Stage 1

只使用文本条件训练全量 Text-to-Motion。部分攻击、原地和击倒动作改善；Jump、Hover、大幅 Root 位移和下半身动态仍弱。

Stage 2

混合 Text-to-Motion 与 Text + Sparse Full-body Keyframe Constraints。关键帧从 GT 自动采样。训练与推理正常，但相较 Stage 1 没有明显且稳定的视觉提升。

问题收敛

  1. 自动 Prompt 存在信息缺失、顺序错误、左右错误、起止不完整和过度简化。
  2. 游戏动作有 Jump、Hover、击飞、倒地和大 Root 位移，与 Kimodo 的稳定站立和 Foot Contact 先验存在 Domain Gap。

五、AI Prompt 转向人工 Gold

自动 Prompt 的典型问题

  • 只保留动作类别，缺少部位、方向和幅度。
  • 忽略起始与结束姿态。
  • 遗漏或改写多阶段顺序。
  • 加入动画中不可观察的情绪、原因和意图。
  • 同类描述风格和粒度不统一。

文本编码能识别明显全局顺序变化，但对局部交换不够敏感。Prompt 必须显式描述“开始、随后、接着、最后”，动作时序仍需单独检查。

8 条人工标签标准

  1. 写出起始姿态。
  2. 按真实时间顺序描述。
  3. 写清身体部位、方向和幅度。
  4. 显式描述离地、落地、浮空和倒地。
  5. 写明结束姿态或持续状态。
  6. 不加入不可观察的情绪、原因和意图。
  7. 多动作切换不能压缩成单一类别。
  8. 同类动作使用统一术语和描述粒度。

七、三维量化评测框架

评测维度回答的问题

Root Trajectory Error

逐帧计算生成动作与 GT 根节点位置欧氏距离并取平均。RTE-XZ 反映水平轨迹，RTE-Y 重点反映跳跃、浮空和下落高度。

Body Pose Error

消除根节点位置与整体朝向后，计算对应关节平均位置误差。BPE-Upper 反映上半身，BPE-Lower 反映腿部、脚部和落地姿态。

九、五条最终结论与边界

  1. 开源权重可以后训练：数据、训练、推理、评测和 Blender 链路已打通。
  2. 游戏动作域可学习：Gold 后 RTE/BPE 下降，Attack、Knocked Down、Hover 改善；Jump / Hover 垂直轨迹仍是瓶颈。
  3. Prompt-Motion 对齐是关键：748 条人工 Gold 比 7,951 条自动标注数据更有效。
  4. 存在 Unseen 泛化：Inplace、Knocked Down、Attack、Hover 保持主要类别与部分时序；Jump 仍不稳定。
  5. 混合训练可以大幅缓解遗忘：Content R@1 38.86% → 95.33%，Repetition R@1 18.84% → 79.54%，游戏域效果基本保持。

当前问题从“能否学会、是否严重遗忘”收敛为“在保持游戏域和 SEED 语义能力时，进一步改善 Jump / Hover、Contact 和 Foot Skate”。

附录一、AI Native 与 R-SDD

AI 承担高频、可验证、可批量的工作，人工负责标签标准、动作核验、异常判断、证据评审和关键决策。AI Prompt 是人工标注候选，不默认作为 Gold；AI 代码必须运行和审查；结论必须由日志、指标、可视化和复现实验支持。

R-SDD 协作循环

研究问题
→ 实验方案
→ 准备就绪审查
→ 实验执行
→ 原始证据登记
→ 独立证据评审
→ 团队决策
→ 修订、复现、采纳或停止

两个门控分别位于实验执行前与实验完成后。项目大脑根据方案、记录、评审和交接信息生成当前状态；research validate 检查冻结方案一致性，research onboard 生成接手数据包。
