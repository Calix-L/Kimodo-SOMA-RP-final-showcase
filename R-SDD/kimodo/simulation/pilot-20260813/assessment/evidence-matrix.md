## Required anti-inflation evidence

- REPLAY is visibly separated from LIVE.
- Agent count is not treated as value by itself.
- Negative and invalid results remain in the Registry.
- A04 cannot edit the frozen evaluation contract.
- A06 does not see A04 private transcript before cold-start completion.
- The final decision is human-owned and cites primary evidence.
- Tool count, command count, document count, and token spend are not scored as outcomes.
